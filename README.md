# Cutopia

A third-person animal collecting game for computers and phones. Open index.html in a browser, or serve this directory as a static website. No build or dependencies needed.

## Controls
Desktop: WASD to walk, Shift to sprint, Space to jump, E to catch, Q to drop fish food, P to pause. Drag the scene to look around.
Phones: left thumb pad to move, drag the scene to look, and use Sprint, Jump, Catch, Pellets, and Pause buttons. Landscape gives the widest view.

## Rules
Rounds last 3:33. Catch animals for immediate points, then jump onto The Nest bed for the same bonus again. Meep needs a speed boost. Eiza chases players and followers; pellets take priority and cause a one-second happy dance. Scores and family photos are saved in this browser's local storage. The leaderboard holds five scores. Photos contain animals delivered to The Nest, randomized realistic scenery, and Eiza lurking behind a cherry blossom tree.

## Characters
Kasanova, Cedonas, and Bronxie.

## Animal points
Meep 1000; Rio 500; Rocky 200; Mama Otter 150; Pom 150; Baby Otter 75; Baby Skunk 75; Cal 62; Baby pygmy goat 60. White bunnies 10, blue 50, rare pink 100; pairs add 50.

## Assets
AI-generated photographic cutouts are embedded in index.html so the game is self-contained. game.js includes gameplay, rendering, touch controls, and photo composition.

## Hosting
For a shareable phone link, serve these two files over HTTPS, for example with GitHub Pages. High scores are stored per browser, not shared online.
